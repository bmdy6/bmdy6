## 怎么用

- **MCP 服务**：每个仓库 README 里都有 Claude Code / Codex / Cursor 的配置片段，复制进去就行。
- **Agent 技能**：按各仓库 README 的安装步骤放进 agent 的 skills 目录。
- **问题和建议**：直接在对应仓库提 Issue。
