## 怎么用

- **公开工具**：从对应仓库查看安装、配置、运行要求和许可证；问题和建议在对应仓库提 Issue。
- **项目实践**：先看项目说明，了解使用流程、设计取舍和当前边界。案例公开不代表源码或在线体验已经开放。
- 同一项目的网页、MCP 和 Skill 入口放在一起，方便按用途选择。
